# 模块接口与信任边界（待实现）

以下约束来自现有 README；具体话题、消息、参数和阈值仍待实现 PR 确认。

- 相机采集 → 图像中继 → 感知：中继转发、遮挡或替换图像内容，保留当前消息时间戳；不改变仿真场景。
- 感知输出视为不可信。记录 clear/blocked 决策、时间戳及其对应前方区域。
- LiDAR、监控器、控制器与速度命令通路受信任。攻击模块不得直接发布机器人运动命令。
- 监控器在共同前方视野内配对相机决策与 LiDAR，明确坐标变换、时间同步容差、持续不一致次数及阈值。
- 可信控制器是唯一最终速度指令发布者，保护停止优先，保持到试验重置。无保护组不得让 LiDAR 参与控制。
- 仿真真值仅用于评价，不提供给控制器或监控器。
- 明确试验重置行为、过期/缺失数据处理和传感器 QoS。
- /scan、/camera/image_raw、/cmd_vel、/odom 是候选名称；实际名称、消息类型与发布订阅方向必须实测记录。

本文件不声明上述接口已实现或运行通过。
